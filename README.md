# TapShare - Modern NFC Contact Sharing

A high-conversion marketing website for NFC business cards targeting Sri Lankan businesses and professionals.

## 🚀 Quick Start

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build for Production
```bash
npm run build
npm start
```

## 🌐 Deployment

### Deploy to Vercel (Recommended)
1. Push code to GitHub
2. Import project to [Vercel](https://vercel.com)
3. Deploy automatically

### Deploy to Netlify
1. Push code to GitHub
2. Connect to [Netlify](https://netlify.com)
3. Build command: `npm run build`
4. Publish directory: `.next`

## 📝 Customization

### Update WhatsApp Number
Search for `94771234567` and replace with your number in:
- `components/Navbar.tsx`
- `components/FinalCTA.tsx`
- `components/FAQ.tsx`

### Update Pricing
Edit `components/Pricing.tsx` to change prices and features.

### Add Real Testimonials
Edit `components/Trust.tsx` to add actual customer reviews.

### Change Brand Name
If not using "TapShare", search and replace throughout:
- All component files
- `app/layout.tsx` (meta tags)
- `components/Navbar.tsx`
- `components/Footer.tsx`
